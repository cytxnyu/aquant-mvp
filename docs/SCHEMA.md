# Schema

This document describes the main CSV/JSON artifacts generated by a run.

## Daily Bars

Normalized input bars use these fields:

| Field | Meaning |
|---|---|
| `date` | Trading date |
| `symbol` | Six-digit A-share symbol |
| `open` | Adjusted open price when using adjusted source data |
| `high` | Adjusted high price |
| `low` | Adjusted low price |
| `close` | Adjusted close price |
| `volume` | Trading volume |
| `amount` | Trading amount |
| `turnover` | Turnover ratio |

## Factor Panel: `factors.csv`

Index-like fields are `date` and `symbol`. Important factor fields include:

- `momentum_20`, `momentum_60`
- `reversal_5`, `reversal_10`
- `volatility_20`, `volatility_60`
- `amount_mean_20`, `amount_mean_60`
- `turnover_mean_20`, `turnover_mean_60`
- `volume_ratio_5_20`
- `price_position_60`
- `ma_bias_20`
- `max_drawdown_60`
- `downside_volatility_20`

All factors are computed from same-day and historical bars only.

## Labels: `labels.csv`

- `future_return_5d`: close at T+5 divided by close at T minus 1.
- `future_return_20d`: close at T+20 divided by close at T minus 1.
- `excess_return_5d`: future 5-day return minus the same-date cross-sectional mean.
- `excess_return_20d`: future 20-day return minus the same-date cross-sectional mean.

Labels are for research evaluation and model training, not for live signal generation.

## Scores And Targets

- `scores.csv`: `date`, `symbol`, `score`, `close`, `amount`.
- `rebalance_targets.csv`: one row per rebalance date, one column per symbol, values are target weights.

## Backtest Outputs

`equity_curve.csv`:

- `date`, `cash`, `market_value`, `equity`, `daily_return`, `running_max`, `drawdown`

`trades.csv`:

- `date`, `symbol`, `side`, `price`, `shares`, `gross_value`, `fee`, `tax`, `cost_basis`, `realized_pnl`, `slippage_rate`, `close`

`holdings.csv`:

- `date`, `symbol`, `shares`, `close`, `market_value`, `weight`

`rebalances.csv`:

- `date`, `equity_open`, `buy_value`, `sell_value`, `traded_value`, `turnover`, `buy_count`, `sell_count`, `target_weight_sum`

## Analysis Outputs

- `factor_ic_summary.csv`: factor-level IC, RankIC, ICIR and observation count.
- `factor_ic_series.csv`: daily IC and RankIC by factor.
- `factor_quantile_returns.csv`: mean forward return by factor quantile and date.
- `factor_coverage.csv`: non-null factor/label coverage.
- `factor_analysis.json`: compact JSON summary for downstream dashboards.

## Run Metadata

- `metrics.json`: backtest metrics.
- `config.json`: resolved run config.
- `load_report.json`: data source and load warnings.
- `manifest.json`: generated timestamp, selected symbols, metrics and output file sizes.
- `summary.md`: human-readable run summary.
