# Data Directory

This directory is intentionally lightweight in git.

- `cache/`: local CSV cache generated by sample or AKShare runs.
- `raw/`: reserved for raw vendor downloads.
- `processed/`: reserved for cleaned point-in-time datasets.

The current demo works with generated sample data and does not require committed market data files. Real A-share research should store cleaned data in a versioned format such as Parquet plus a manifest describing source, fetch time, adjustment mode and schema version.
